# Phase 7: Expressibility & Entanglement Analysis

This phase provides a deep theoretical dive into the "Quantum Rigor" of the models developed in previous phases. We analyze the **full 17-qubit production PQC** -- the exact architecture deployed in Phase 5 experiments -- to understand its capacity to explore the Hilbert space and its ability to generate entanglement.

## Scientific Objectives
*   **Expressibility:** Quantify how well the PQC can represent arbitrary states in the Hilbert space compared to a Haar-random distribution. Measured using the Kullback-Leibler (KL) divergence between the fidelity distribution of the PQC and the Haar distribution.
*   **Entanglement:** Measure the global entanglement generated by the PQC using the **Meyer-Wallach Measure**.
*   **Bootstrap Confidence Intervals:** All metrics include bootstrap 95% CIs for statistical reliability.

## Architecture Analyzed

The `create_production_pqc()` function constructs the exact Phase 5 circuit:

| Component | Detail |
| :--- | :--- |
| **Total qubits** | 17 (16 data + 1 readout) |
| **Data qubit layout** | `cirq.GridQubit.rect(4, 4)` -- 4x4 grid |
| **Readout qubit** | `cirq.GridQubit(-1, -1)` |
| **Entanglement layer** | 16 CZ gates: 15 in linear chain across data qubits + 1 connecting last data qubit to readout |
| **Parametric gates per layer** | 16 XX + 16 ZZ = 32 trainable parameters |
| **Layer sweep** | 1, 2, 3 layers |

This is a direct replica of `phase5/quantum_k_classifier.py::create_k_category_quantum_model`, stripped of the observable definitions (not needed for expressibility/entanglement analysis).

## Methodology

We compute expressibility and entanglement for the production 17-qubit circuit across 1-3 parametric layers:

- **Expressibility**: 500 fidelity samples (pairs of random parameter sets), KL divergence from Haar distribution, with 500 bootstrap resamples for 95% CI.
- **Entanglement**: 50 Meyer-Wallach samples (random parameter sets, partial traces over all 17 qubits), with 5000 bootstrap resamples for 95% CI.
- **Seeding**: All RNG streams are deterministic (`seed=42 + offset`) for full reproducibility.

Sample counts are reduced relative to a smaller circuit because 17-qubit statevector simulation involves 2^17 = 131,072-dimensional complex vectors.

## Expected Results

1. **Expressibility** (KL divergence) should decrease with more layers, indicating the PQC approaches the Haar distribution and explores the Hilbert space more uniformly.
2. **Entanglement** (Meyer-Wallach) should increase with depth, showing the circuit generates more global entanglement across all 17 qubits.
3. Results include 95% bootstrap CIs -- overlapping CIs between layer counts indicate the difference may not be statistically meaningful.

## Limitations

- **Noiseless simulation**: All circuits are simulated with exact statevector computation. Real hardware noise (decoherence, gate errors, readout errors) is not modelled. Expressibility and entanglement on actual NISQ devices would likely be lower.
- **Reduced sample counts**: For computational feasibility under AMD64 emulation on ARM64, sample counts are lower than ideal. Higher counts would yield tighter confidence intervals.
